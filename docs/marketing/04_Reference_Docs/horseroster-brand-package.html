07

Brand Usage Rules

Concise rules that protect the identity. Follow these to keep the brand clean and premium at all times.

Logo Clearspace

Maintain a minimum clearspace equal to the cap-height of the "H" in HorseRoster on all four sides. Never place content, borders, or images inside this zone.

× H × H × H × H
Horse Roster

Minimum Sizes

Wordmark: 80px wide minimum on screen. 20mm in print. Icon mark: 16px minimum. Below these sizes, use the monogram only.

Approved Colour Combinations

Use these pairings only. Approved = meets WCAG AA contrast.

Aa
Navy on White / Off-white ✓ AA
Aa
Cream on Navy ✓ AA
Aa
Cream on Hunter Green ✓ AA
Aa
Charcoal on Off-white ✓ AA

Do

Use approved colour combinations only
Maintain the bold/light weight split in the wordmark
Use DM Sans as the primary typeface
Keep generous whitespace around the logo
Use the H icon for app and small-format contexts

Don't

Stretch, distort or rotate the logo
Change the weight split (make both bold or both light)
Place on a busy photographic background without overlay
Use hunter green for decorative purposes
Add drop shadows, glows, or gradients to the logo

Background Usage

The logo works on these backgrounds. When placing on photography, use a semi-transparent navy overlay at 70% minimum.
